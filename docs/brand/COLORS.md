# Hourforge brand colors

Inspired by Outlook-style layered blues.

| Role | Hex | Use |
|------|-----|-----|
| Base blue | `#2CB4EB` | Primary actions, icon tile, links |
| Base blue alt | `#25AEE8` | Gradients, hover, secondary accent |
| Deep accent | `#0B5CAD`–`#0A4F9C` | Contrast panels, headers |
| Text | `#0F172A` | Body / wordmark |
| Surface | `#F4F8FC` | Soft page background |
